## Contents
- `om_HW6.ipynb`: the homework notebook, with all outputs.

## Data
APS Failure at Scania Trucks, UCI Machine Learning Repository:
https://archive.ics.uci.edu/ml/datasets/APS+Failure+at+Scania+Trucks

The notebook expects `aps_failure_training_set.csv` and `aps_failure_test_set.csv`. The data files are not included in this repository; update the two file paths in the data-loading cell to point to your copies.
